# Prerequisites

Tools and packages needed for a fresh machine setup.

## Window Manager / Desktop

- `i3blocks` - status bar
- `rofi` - application launcher
- `dunst` - notification daemon
- `brightnessctl` - backlight control
- `xset` - X settings
- `xsetroot` - root window settings
- `hsetroot` - root window background
- `xmodmap` - keyboard remapping
- `xmousepasteblock` - block middle-click paste
- `greenclip` - clipboard manager
- `flameshot` - screenshot tool
- `xfce4-power-manager` - power management
- `brightnessctl` - controlling brightness

## Terminals

- `alacritty`
- `xfce4-terminal`
- `tmux` + [tpm](https://github.com/tmux-plugins/tpm) plugin manager

## Audio

- `pulseaudio` - audio server (provides `pactl`)
- `pavucontrol` - PulseAudio volume control GUI

## Fonts

- Fantasque Sans Mono
- FontAwesome

## Editors

- `emacs`
- `neovim` or `vim`
- `code` (VS Code)

## Browsers

- `firefox`
- `google-chrome-stable`

## File Managers

- `thunar`
- `ranger`

## Shell Utilities

- `autojump` - directory navigation
- `hstr` - bash history search
- `keychain` - SSH key agent

## Development

### Languages / Runtimes
- Rust (`cargo`)
- Node.js via `nvm` or `nvs`
- Java via `sdkman` (java-17-openjdk)
- Clojure: `babashka`, `bbin`

### Tools
- `kubectl` - Kubernetes CLI
- `kubens` - Kubernetes namespace switcher
- `terraform`
- `ghcid`, `hoogle` - Haskell tools
- `dbeaver-ce` - database client

## Network

- `nm-applet` - NetworkManager tray applet
- `nordvpn` (optional)

## Other Applications

- `1password`
- `dropbox`
- `acpi` - battery status (for laptops)
